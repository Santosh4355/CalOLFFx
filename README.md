# Shiny App for OLFF
A Shiny app for olive fruit fly (OLFF) monitoring, visualization and decision support.

### Overview
This repo holds the source code for a Shiny web application built to support workflows for olive fruit fly research and management. The app is designed to enable users to explore data related to OLFF, visualize outputs and support applied decision making within agricultural or IPM settings.

## Features 
- Interactive Shiny interface for OLFF related analyses.
- Available for end users via browser.
- R/Shiny workflow for research, extension and decision-support applications.

## Platform 
The app is written in R using the `shiny` package and is meant to be used in a browser. The `shiny` package is licensed under GPL-3, and Shiny Server is typically installed on Linux systems such as Ubuntu/Debian, RedHat/CentOS, and related distributions.

# Shiny App for OLFF
A Shiny app for olive fruit fly (OLFF) monitoring, visualization and decision support in California.

### Overview
This repository holds the source code and data resources for a Shiny web application built to support workflows for olive fruit fly research and management. The app is designed to enable users to explore data related to OLFF, visualize outputs and support applied decision making within agricultural or IPM settings in California.

## Features 
- Interactive Shiny interface for exploring the OLFF population in California.
- R/Shiny workflow for research, extension and decision-support by integrating OLFF population data with weather based correlation and analysis.
-  Available for end users via web browser.

## Platform 
The app is written in R using the `shiny` package and is meant to be used in a browser. The `shiny` package is licensed under GPL-3, and Shiny Server is typically installed on Linux systems such as Ubuntu/Debian, RedHat/CentOS, and related distributions.
